Cybersecurity Incident Investigation Report

Incident ID INC-2026-0842 Severity Level HIGH / CRITICAL
Target System HealthGuard Medical Centre - Auth Server Investigation Date September 21, 2026
Lead Analyst SOC Security Engineering Team Status Remediated / Closed

1. Executive Summary

On September 18, 2026, an automated alert triggered in the primary SIEM indicating anomalous authentication attempts targeting internal infrastructure. Subsequent packet analysis (PCAP) and Sysmon host event logs confirmed an external brute-force attempt leading to unauthorized credential access on host 10.0.4.15.

2. Threat Vector & Technical Analysis

  • Initial Access: Port scan identified open SSH (Port 22) and HTTP (Port 80) on external perimeter interface.
  • Attack Mechanism: High-frequency automated dictionary attack originating from malicious IP 192.168.1.105.
  • Forensic Artifacts: Sysmon Event ID 4625 (Failed Logon) spikes exceeding 450 attempts within 3 minutes, followed by Event ID 4624 (Successful Logon).

3. Indicators of Compromise (IOCs)

Attacker IP 192.168.1.105
Compromised User svc_admin
Malware / Tool Hash e99a18c428cb38d5f260853678922e03 (SHA256)

4. Mitigation & Remediation Actions

  1. Blocked source IP 192.168.1.105 at perimeter firewall ruleset.
  2. Reset credentials for account svc_admin and enforced multi-factor authentication (MFA).
  3. Implemented rate-limiting (fail2ban) on SSH endpoints to throttle rapid authentication failures.
