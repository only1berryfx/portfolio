SIEM Detection & Event Logging Lab

This lab demonstrates automated log ingestion, event correlation, and detection queries built in Splunk SIEM for monitoring brute-force authentication attacks.

Detection Rule (Splunk SPL)

index=security sourcetype=sysmon EventCode=4625
| stats count by src_ip, user
| where count > 20
| sort - count

Status: Homelab architecture operational. Logs forwarded via Sysmon Universal Forwarder.
